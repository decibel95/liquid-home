Colour controls: variants CHO-20

Apple-like ways to set colour temperature and colour on the light card, each shown with Ceiling Lights (2631 K) and Kitchen Lights (colour), on dark and light glass. The vertical brightness slider (TOK-1 to TOK-4) is unchanged. No thumb circles, no second glass layer, no glow, only existing colour values. V1 chosen (18 Nov), not yet gate-approved. V1 goes on the light card itself with three mode buttons; the hi-fi light cards now use it. V1b is shown for comparison; V2 and V3 are kept for the record.
For reference: the v20 bar marker (TOK-6), not liked
V1 fills with the toned spectrum (TOK-21, 13 stops at 3.15:1), so the fill edge keeps 3:1 against the track (CON-15). V1b and V3 use the raw spectrum (TOK-7). Drag feel is settled in the gate 2 prototype.
