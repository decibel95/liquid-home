Config

The editor writes this. Every sensor defaults to auto; set an entity id to override or false to hide.

type: custom:liquid-climate-card
entity: climate.keuken_airco
name: Living Room
temperature_sensor: sensor.woonkamer_temperatuur
sensors:
  humidity: auto
  outdoor: auto
  energy: auto
  cloud_limit: auto
  health: auto
controls:
  modes: [off, heat, cool, heat_cool, dry, fan_only]
  fan: true
  swing: true
  swing_horizontal: true
  presets: true
write_delay: 1.5
status_entities:
  - entity: input_text.woonkamer_auto_stand
    name: Automation
look:
  glass: dark
  tint: 0.09
  blur: 30
  motion: rich
config_version: 1
type: custom:liquid-climate-cluster
group_by: area
exclude:
  - climate.guest_room
names:
  climate.keuken_airco: Living Room
order: auto
tap_action: open_dial
config_version: 1
Rules for the schema
  • Only entity is required. The rest has a default.
  • Controls hide when the entity does not support them, whatever the config says.
  • config_version lets updates migrate old configs silently.
  • Theme variables (--lc-tint, --lc-blur, --lc-radius) override look from an HA theme.

Sensor detection

Search the device family: the climate entity's device plus every device whose via_device points to it. Match on device class, unit and translation key, never on the entity name.

RoleGeneric ruleDaikin Onecta extra
Humiditysensor, device_class humidityregeling device
Outdoor temptemperature sensor with an outdoor translation keyoutdoor temperature on regeling
Unit tempother temperature sensor in the familyflags whole-degree readings, suggests a room sensor
Energydevice_class energy, split by heating and cooling, period from translation key8 sensors: day, week, month, year

Docs

README: quick start in 3 steps, a GIF per card, Marketplace badge.
Docs site: GitHub Pages. Getting started, one page per card, full config reference, detection rules, theming.
Gallery: one unit, whole house, wall tablet. Screenshot plus YAML to copy.

Help links: every (?) in the editor opens the matching docs anchor.
